# Changelog

## 0.1.0-beta.1

- Shared Rust engine and native Tauri desktop project studio.
- Portable projects, validated local asset import and literal APK manifest inspection.
- Three themes, screenshot captions, four live preview formats and staged release exports.
- Separate CLI with JSON envelopes, explicit exit codes, schema, validation and dry-run.
- Native release workflow for Windows x64, Linux x64 and macOS Apple Silicon.
- MIT source and original icon; Noto fonts under SIL OFL.

Unsigned beta; signature verification, automatic store publishing and notarization are outside this version.
