# Documentation map

- REQUIREMENTS.md and PLAN.md: scope, architecture and release gates.
- CLI.md and AGENT_QUICK_START.md: executable commands and JSON contract.
- PROJECT_FORMAT.md and launchkit-project.schema.json: portable user-project format.
- BUILD_AND_RELEASE.md and INSTALL.md: native builds, downloads and verification limits.
- RELEASE_NOTES.md: current beta notes.

- guide.md: everyday commands and release process.
- PRODUCT_STANDARD.md: company-wide folder and ownership rules.
- design/: product-specific design documentation.
- store/store-listing.json: actual product listing facts; no store submission is claimed.
- website/: current editable product metadata and privacy JSON.
- schemas/: machine-readable contracts.
- verification/: concise evidence summary and ignored local build logs.
- archive/: ignored historical plans/delivery drafts preserved for reference.
